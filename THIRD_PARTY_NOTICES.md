  Copyright © 2011-2026 Anish Shankar, Lakshminarayanan Srinivasan, Madhavan Malolan, and the Android DC++ project contributors.
- **License Text:** See root `LICENSE` file and in-app Open Source Licenses screen.
- **TLS certificates (NMDCS / ADCS):** the app's own self-signed X.509 certificate (RSA-2048, SHA256withRSA) is
  generated by original code in `com.phinvader.libjdcpp.tls.SelfSignedCertificate` (a small DER encoder over the
  platform's `java.security` APIs). No certificate library such as BouncyCastle PKIX is bundled for this.
  The Tiger hash in `util/TigerDigest` remains adapted from Bouncy Castle (MIT licence, notice in that file).
